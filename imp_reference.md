

### What I would use for your Anfinity work

I'd bookmark these **three**:

1. **[AI Landing Page Design](https://github.com/kgoedecke/ai-landing-page-design)** — best structured design systems
2. **[MotionSites 813 prompts](https://github.com/nomaan5541/motionsites-prompt-collection)** — best large prompt collection
3. **[Superdesign prompts](https://github.com/superdesigndev/superdesign-prompts)** — best for browsing different visual directions

Then we can create your own **`website-prompts.md`** based on the best patterns from these repositories, organized by **business type + visual style + purpose**. That would be much more useful for you than trying to remember where individual prompts came from.
